# 给审核员：Squeek Merge Preview

这不是链上数据展示页，而是持有人合并前的非托管决策台：选 Squeek → 前后对照与后悔点 → 本地快照 → 理解不可逆后才给出官方合并检查单；站点本身不发起合并交易。

## 为什么是 holder utility

主任务是一项具体的持仓决策。用户指定保留方和被合并方，再比较 Day 0、+7 天、+30 天的 NFT 数量、会失去的 tokenId、等级、算力规则、冷却、流动性及不可知因素。选择、互换、情景假设和后悔点都会改变当前工作状态，不是只读数字墙或链接集合。

用户可以在同地址下保存多份 Baseline、选择三份并排比较，导出 JSON、复制摘要、下载署名图片。快照只存在本机浏览器中；历史基线可在当前读取失败或 donor 已消失后独立查看。保存的结论保持当时的值，当前规则只用于新的预演。

## 两分钟审核路径

1. 无需钱包，打开默认「我的收藏」，选 #1001 糯米团与 #1003 芝麻球。20 条固定持仓来自任务简报，昵称不是食物主视觉；卡面为仓鼠肖像。
2. 查看 11 行带「确定 / 情景 / 不可知」标签的对照。切换区块速度假设，注意 +7 天与 +30 天分别按各自时点判断冷却。工具不预测 APY 或市价。
3. 保存三份快照，刷新并打开任意一份。历史视图展示保存时间、持仓和数据源，不能修改假设；用「返回当前预演」继续选择。清除浏览器缓存会丢失快照。
4. 检查右栏：理解不可逆之前检查单锁定；勾选后只提供网络、合约、只读方法名、风险与官方链接。签名弹窗预览只显示 UI。
5. 切换 ZH / EN，并在手机宽度检查。钱包入口可用浏览器钱包连接，也可粘贴地址只读加载。失败会明确提示；RPC 不把公共质押合约保管的 NFT 归到任意查询地址。

## 边界与证据

产品不代签、不保管私钥或助记词、不托管 NFT/代币，不调用合并、授权、发送交易或签名。所有页面状态、快照及分享图在浏览器内生成。钱包与内置收藏的数据和快照隔离，chainId 固定为 Sepolia 11155111。

新快照保存可双语重现的结论；修订前的快照未保存规则参数，无法找回其历史数值，相关项明确显示不可知。官方应用、API 可用性与真实钱包行为依赖外部服务；本轮回归使用确定性夹具，未声称完成真实签名或实时服务认证。
